# Legacy Liberation font source

The donor bundles Liberation Sans Regular version 1.05, not the OFL-licensed 2.x font. Its original TTF is preserved here from the pinned donor's scripts/woff2/assets/LiberationSans-Regular.ttf. The distributed WOFF2 is unchanged in packages/excalidraw/fonts/Liberation.

The bundled font metadata is retained verbatim in public/FONT_NOTICES.txt. For the legacy font, public/licenses includes GPL v2 and the official Liberation legacy license/exception, obtained from https://github.com/liberationfonts/liberation-sans-narrow/blob/main/License.txt on 2026-10-11. The upstream distinction between legacy GPL-with-exceptions and OFL 2.x is documented at https://github.com/liberationfonts/liberation-sans-narrow/blob/main/README.rst. These font terms are separate from the editor donor's MIT license; no font was relicensed.
